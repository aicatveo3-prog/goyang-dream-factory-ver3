게임 개요

한 문장 소개

꿈제작소 건물 안에서 휴대폰 카메라를 비추면 가상의 청년 캐릭터를 만나고, 대화하고, 카드를 수집하며, 밤이 되면 그 건물의 비밀을 풀어가는 현장형 AR 카드 어드벤처 게임.

기본 정보

항목내용
게임명YOUTH ECHO (유스 에코)
장르현장 AR 카드 수집 + 2.5D 미스터리 탐사 + 턴제 배틀
플랫폼모바일 웹 (앱 설치 불필요, 브라우저 접속)
소요 시간30~60분
대상꿈제작소 행사 참가 청년
참가 조건스마트폰 + 인터넷 (회원가입·앱 설치 없음)
장소내일꿈제작소 (경기도 고양시) 건물 내부
핵심 원칙개인정보 일절 수집하지 않음

경품 수령

① 시작 — 진입 장벽 제로

  • 행사 안내 QR을 스캔하거나 주소를 입력하면 바로 시작
  • 회원가입·로그인·전화번호 인증 없음
  • 첫 화면에서 "개인정보를 수집하지 않습니다" 안내 확인

② 현장 AR 탐험

  1. GPS 확인: 꿈제작소 반경 안인지 자동 확인
  2. 카메라 실행: 실제 공간이 화면에 보임
  3. 청년 출현: 카메라 위에 가상 캐릭터가 나타남
  4. 방향 연동: 실제로 몸을 돌리면 캐릭터가 따라 이동
  5. 터치 → 대화 시작
[ AR 조우 화면 캡처 — 카메라 배경 위에 청년 캐릭터가 서 있는 모습 ]

③ 청년과의 대화 (3턴 선택지)

서하늘 (꿈꾸는 청년):
"오늘은 어떤 꿈을 기록하고 있었어?"

✅ "그 꿈이 구체적으로 어떤 모습인지 들려줄래?"
❌ "그럴 시간에 취업부터 해야 하지 않을까?"

  • 공감하는 선택지를 고르면 대화가 이어진다 (3턴)
  • 3턴 모두 성공 → 카드 획득 + 호감도 상승
  • 실패 → 패배가 아닌 다른 위치에서 새 만남 기회

④ 도감 — 관계 기록

  • 청년의 이름, 성격, 만난 장소, 호감도 게이지
  • 해금된 대화 기록 열람 가능
  • 배틀에서의 팀 역할 안내
  • 카드 5장 이상 수집 시 야간 스토리 해금

⑤ AR 기록 저장·공유

  • 청년을 만난 순간을 이미지(1080×1920px)로 저장
  • 카카오톡·인스타그램 등으로 바로 공유 가능

배틀 시스템

스토리 진행 중 한숨덩이(중간 보스)와 이상한 박사(최종 보스)를 만나면 카드 배틀이 시작됩니다.

배틀 진행 순서

카드 3장 선택
→
조합 유형 판정
→
대표 속성 결정
→
상대와 상성 비교
→
HP 반영

① 카드 조합 유형

조합조건대표 속성 결정예시
몰빵3장 모두 같은 속성자동으로 그 속성체력+체력+체력 → 체력
페어2장이 같은 속성겹친 속성이 대표감정+감정+분석 → 감정
무지개3장 전부 다른 속성첫 번째 카드가 리더도전+영감+체력 → 도전 (배치순서 = 전술)

② 5속성 상성 순환

감정 → 분석 → 체력 → 영감 → 도전 → 감정
화살표 방향이 이김 · 예: 감정은 분석을 이기고, 분석은 체력을 이긴다
속성이기는 대상배틀에서의 의미
감정분석을 이김"본능의 결과값이 분석을 앞질렀다."
분석체력을 이김"정확한 분석이 체력을 넘어 결론에 닿았다."
체력영감을 이김"실현할 힘이 영감을 밀어냈다."
영감도전을 이김"발상이 도전의 벽을 돌아갔다."
도전감정을 이김"포기한 감정을 다음 발로 넘어섰다."

상성 없는 쌍: 감정–체력, 분석–영감, 체력–도전, 영감–감정, 도전–분석
→ 이 경우 카드 레벨이 높은 쪽이 이김 (같으면 무승부)

③ 이상한 박사의 특수 능력: 속성 복제

박사는 직전 턴에 참가자가 낸 대표 속성을 다음 턴에 복제합니다.
따라서 매 턴 대표 속성을 바꾸는 전략이 필요합니다.
3라운드 중 2승을 하면 승리!

④ 승리 후 분기 엔딩

엔딩 A: "원본 카드 보존"

야간 스토리 탐사

카드를 5장 이상 수집하면 해금됩니다. 불이 꺼진 꿈제작소를 위에서 내려다보는 시점으로 탐사합니다.

조작 방법

  • 바닥을 터치하면 캐릭터가 해당 지점으로 이동
  • 벽이나 가구에 부딪히면 멈추고 안내 메시지 표시
  • 계단·엘리베이터 아이콘을 터치하면 다른 층으로 이동
  • 관심 지점(?)을 터치하면 단서·사건 발생

탐사 가능 공간 (5개 구역)

구역주요 장소핵심 이벤트
A동 1층코워킹, 북스텝, 카페, 스튜디오, 스터디룸화장실 세 번째 칸 (첫 단서)
A동 2층코워킹 B, 거버넌스룸, 컨설팅룸, 세미나실뒤집힌 캔버스 발견
A동 3층세미나실, 클래스룸화가 조우 + 한숨덩이 배틀
A동 4층강당, 인터뷰룸, 라운지이상한 박사 최종 배틀
B동내일꿈갤러리, 신체활동실, 입주공간캔버스 단서 + 한숨덩이 배틀

미스터리 스토리라인

핵심 사건: "폐관 후 꿈제작소에서 누군가 청년들의 꿈 카드를 복제하고 있다."

단서 01 — 세 번째 칸

1층 스터디룸 화장실 세 번째 칸. 변기 뚜껑 아래에서 젖은 카드 조각을 발견했다. 복제 신호는 위층으로 이어진다.

단서 02 — 뒤집힌 캔버스

2층 컨설팅룸 / B동 갤러리. 캔버스 뒤에 복제 기록의 일련번호와 '원본을 찾아라'라는 문장이 남아 있다.

단서 03 — 화가의 고백

3층 클래스룸. 화가는 밤마다 캔버스를 뒤집었다. 그림 속 꿈이 복제 장치에 빨려 들어가는 것을 막기 위해서였다.

최종 — 이상한 박사

4층 연구실. 박사는 원본 카드의 힘이 약해지는 것을 알면서도 복제를 멈추지 않았다. 청년 3명의 조합으로 맞서야 한다.

경품 코드 원칙

  • 코드는 한 번만 쓸 수 있고, 24시간 후 자동 만료
  • 참가자의 이름이나 전화번호와 코드가 연결되지 않음
  • 종이 입장권의 무작위 번호로만 중복을 방지
  • 코드 원문은 발급 시 한 번만 화면에 표시되고, 서버에는 저장되지 않음

운영자가 하는 일

  1. 참가자의 게임 완주 화면을 확인한다
  2. 종이 입장권(또는 QR)의 무작위 번호를 확인한다
  3. 운영자 전용 화면에서 코드를 발급한다
  4. 경품 데스크에서 코드를 한 번만 사용 처리한다

네트워크 장애 대비: 인터넷이 끊겨도 종이 입장권 + 오프라인 대장 + 도장/스티커 3중 확인으로 경품 처리가 가능하도록 이중 운영 체계를 갖추고 있습니다.

교육적·문화적 가치

왜 "카드 수집 + 대화"인가

  • 10명의 청년 캐릭터는 각각 꿈·일·도전·쉼·감정이라는 청년기의 보편적 고민을 대변합니다.
  • 대화의 정답은 항상 공감과 응원입니다. 자연스럽게 "상대의 속도를 존중하는 태도"를 경험합니다.
  • 배틀은 폭력이 아닌 "청년들이 서로의 강점을 조합해 함께 문제를 해결하는 것"으로 설계되었습니다.

왜 "꿈제작소 현장"인가

  • 참가자가 실제로 건물을 돌아다니며 공간을 체험합니다.
  • 캐릭터가 각 공간(북스텝, 카페, 스터디룸 등)에 배치되어 자연스럽게 꿈제작소의 구석구석을 알게 됩니다.
  • "여기서 이런 일을 할 수 있구나"를 게임 속에서 발견합니다.

왜 "개인정보 미수집"인가

  • 참가자의 진입 장벽을 완전히 제거합니다 (1~3분 안에 체험 시작).
  • 행사 후 데이터 관리 부담이 없습니다.
  • 참가자와 운영 기관 사이의 신뢰를 높입니다.
