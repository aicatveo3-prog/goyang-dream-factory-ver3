MINIMUM SECURITY LOGGING
필요한 사건만 기록하고 짧게 보관한다

기록 한다

  • 코드 발급·수령의 성공/실패
  • 발급·수령 시각과 코드 상태
  • 운영자 권한 실패와 반복 시도
  • 서비스 연결·DB 오류 같은 운영 사건

경품 중복 수령 방지와 장애 대응에 필요한 최소 사건만 기록합니다.

기록하지 않는다

  • 완주 코드 원문·입장권 번호 원문
  • 세션값·인증 토큰·비밀번호
  • 전화번호·이름·GPS 좌표·카메라 영상
  • 게임 대화·개인적 게임 진행 내용

민감값은 원칙적으로 제외하고, 필요 시 해시·마스킹합니다.
